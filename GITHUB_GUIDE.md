# GitHub Upload Guide

```bash
git init
git add .
git commit -m "Initial commit - Intelligent Customer Complaint Analytics"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Before pushing, create a `.gitignore` and do not upload secrets or virtual environments.

## Suggested repository description

Machine-learning powered customer complaint analytics platform for classification, sentiment analysis, priority detection and service-performance insights.
